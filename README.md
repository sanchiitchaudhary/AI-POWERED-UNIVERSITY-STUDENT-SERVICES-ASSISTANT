# 🎓 UniAssist AI | AI-Powered University Student Services Assistant

> **HCL Hackathon 2026 Submission**  
> An autonomous, 24/7 multi-modal AI assistant and unified student services web portal built for modern higher education institutions.

---

## 🌟 Key Features & Capabilities

### 1. 🤖 Autonomous RAG Student Copilot & Voice Assistant
- **24/7 Intelligent Inquiry Resolution**: Instant answers regarding course prerequisites, graduation requirements, fee deadlines, hostel rules, and visa compliance.
- **Voice Assistant Integration**: Interactive Web Speech API voice synthesis and speech recognition with real-time waveform visualizers.
- **Auto-Escalation to Registrar**: Automatically formats and converts complex unresolved student inquiries into official administrative support tickets.

### 2. 📜 Instant Official Transcripts & Bonafide Letter Generator
- **Digitally Sealed Documents**: Generates verified Official Grade Transcripts and Bonafide Certificates.
- **Cryptographic Verification**: Includes registrar digital checksum hash and QR verification links.
- **Print & PDF Support**: One-click download & print layout formatted to university registrar standards.

### 3. 📊 Academic & Degree Audit with Target GPA Simulator
- **Interactive GPA Projection**: Drag sliders to project required term GPAs needed for Dean's Honor status or target graduation CGPA.
- **Degree Progress Tracker**: Visual breakdown of completed core, elective, and lab credits.
- **Smart Course Registration Helper**: AI recommended course cart for upcoming semesters.

### 4. 💳 Financial Aid, Fees & Instant Receipts
- **Tuition Ledger**: Detailed breakdown of tuition, lab compute fees, and hostel dues.
- **Scholarship Management**: Direct tracker for merit awards (e.g. HCL AI & Innovation Excellence Award).
- **Payment Gateway & Receipt Simulator**: Instant verifiable PDF receipt generator.

### 5. 🎟️ Smart Administrative Support Desk & Ticketing
- **AI Auto-Categorization & Priority**: Tickets tagged by department (*Registrar, Bursar, Housing, Academic Affairs*).
- **Live Thread Activity**: Real-time message exchange between students, AI assistant, and university administration.

### 6. 🏠 Housing, Dining & Campus Life
- **Hostel Room Management**: Real-time room status (*Block B Room 402*), Wi-Fi connection info, and 1-tap maintenance request button.
- **Digital Meal Card Top-Up**: Interactive balance top-up simulator and daily cafeteria menu tracker.

### 7. 📅 1-on-1 Advisor Consultation Scheduler
- **Faculty Appointment Slot Booking**: Book video/in-person meetings with Primary Academic Advisors and Career Counselors.

### 8. 🚨 Emergency Safety & Student Welfare
- **1-Tap SOS Alert**: Instant panic button dispatching student location to Campus Police and Medical Services.

## 🛠️ Technology Stack

- **Frontend Core**: React 19 + TypeScript + Vite
- **Styling & Theme**: Tailwind CSS v4 + Custom Glassmorphism UI Design System
- **Icons**: Lucide React
- **Animations & Effects**: Custom CSS keyframes + Canvas Confetti
- **Document Engine**: CSS Print Layout + HTML Canvas QR checksum

## 🚀 Quick Start Guide

### Prerequisites
- Node.js (v18.0.0 or higher)
- npm or yarn

### Installation & Execution

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/sanchiitchaudhary/AI-POWERED-UNIVERSITY-STUDENT-SERVICES-ASSISTANT.git
   cd AI-POWERED-UNIVERSITY-STUDENT-SERVICES-ASSISTANT
   ```

2. **Install Dependencies**:
   ```bash
   npm install
   ```

3. **Run Development Server**:
   ```bash
   npm run dev
   ```

4. **Build Production Bundle**:
   ```bash
   npm run build
   ```
